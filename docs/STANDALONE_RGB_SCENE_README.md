## Implemented callgraph

`prepare_rgb_scene_runtime.py` creates a curated code/assets bundle and a fresh raw-input contract. The native model-assisted executor runs `run_rgb_scene_stage.py`:

1. `frontend/P01` → decoded full CFR frames.
2. `camera` → supplied/estimated K, camera-conditioned UniDepth, exact depth-camera binding, HaWoR full MANO.
3. Actual current-image object plan → OWLv2 → SAM2 → MANO/camera base annotations → retained object-owned depth → actual visual anchor and rigid decision → P11.
4. `geometry` → fresh native SAM3D/P13; `initial-pose` → anchor-bound initial P14 observations.
5. `refined-pose` → current SuperPoint/LightGlue and retained-source-depth PnP → robust global SO3 → refreshed observed/RGB full-SE3 graph. All timeline nodes remain, including uncertain missing-metric rows. Source observations are preserved separately.
6. `appearance` → independent raw-SAM2 appearance evidence; actual visual appearance-anchor judgment → `native-shape` → a second native reconstruction conditioned on that appearance.
7. `shape` → full native pose replay, metric front-depth similarity, refined canonical binding and static full-triangle silhouette scale. This explicitly consumes refined rows, never old readiness/fallback logic.
8. Actual interaction/visibility judgments → `visual-fit` → existing full MANO LBS, articulation/wrist-root, camera-origin hand similarity, projection priors and unsigned triangle-pad fitting, guarded by a typed refined binding.
9. `export` → complete object/MANO triangles, transforms, camera/K, camera trajectory, named time/frame/decode axes and embedded source RGB in RRD; source/refined/fitted numeric poses, hand parameter provenance, visibility and uncertain interaction in JSON. No annotation MP4 or raytraced image is generated by this exporter. Internal state/meshes remain under measurements/state.

The exact OLD published `milk_hand_object_demo.rrd` identified in the design is the reference—not a different V16 recording. Its historical files/rotations are **not runtime inputs**. Developer-only comparison showed approximately 53–70° late relative-camera orientation differences from the current baseline, including camera-estimate differences; this is not a GT error. The implemented correction is upstream active relative rotation/SE3 evidence, not an attempt to infer orientation from the final silhouette loss alone.

## Explicit scope and differences from legacy heuristics

- One selected rigid object, full-video CFR, optional target description, dynamic case/object/track and source aspect. Current raw frontend uses zero-based decoded IDs; graph/export independently support noncontiguous IDs and irregular timestamps. This does **not** claim the HaWoR frontend supports VFR. Supplied unequal fx/fy is rejected by the inherited HaWoR model API, not averaged.
- A native vision-capable executor must inspect images and author object, anchor, rigid, appearance-anchor, interaction and visibility decisions. There is no fictitious unattended Python/VLM planner. Its tool provider, pinned environments and licensed MANO assets must exist before prediction.
- Numerical kernels are extracted from `fit_v20_late_window_prediction_only_se3.py`; relative SO3 residuals use `Log((Rt Rs.T) Rmeasured.T)`. Translation uses world motion `tt-(Rt Rs.T)ts`, not canonical-registration convention. Reprojection recovers fixed source-world observations using the hashed producer pose, then differentiates both candidate endpoints. No generated vertices enter pose factors.
- Source priors and optimizer states are distinct. One selected retained-metric anchor is eliminated from optimization to fix gauge. Soft priors weaken with missing metric evidence. SO3 and SE3 use sparse robust least squares, bounded successive retractions and descent/backtracking; there is no small accumulated rotation bound. Timestamp-based correction velocity and actual acceleration use continuous-time quadrature. Disconnected relative-evidence nodes remain explicitly uncertain, without invented loops.
- RGB quality now sets precision rather than rejecting a corrective edge merely for disagreeing with P14. Insufficient PnP support, invalid transforms and cheirality remain mechanical failures. Point correspondences refresh in current canonical coordinates. Native masks and retained metric support remain distinct.
- Final MANO fitting retains its validated 960-width image-loss normalization, full topology, supported temporal interpolation, fixed beta, camera-origin similarity, bounded local object correction and closest-three-of-twelve pad logic. The upstream graph—not this small object correction—repairs large rotation drift. Historical signed intrusion is deliberately not restored; generated normals do not establish inside/outside or collision truth.
- Static scale keeps a bounded [.8,1.2] image grid around the full mesh vertex-mean pivot. An uninformative grid chooses scale 1 by least-intervention tie-breaking and preserves uncertainty instead of failing. The native front-depth similarity retains the existing numerical sanity contract. Appearance scoring only proposes candidates; the native executor supplies the actual selected anchor.
- RRD object geometry is logged temporally at first appearance/reappearance, with explicit clears. This avoids stale static geometry and avoids repeating a large static mesh every frame. Both full MANO surfaces are time-indexed, with clears for missing hands. Numeric source/calibration provenance is portable; mesh/NPZ paths are not loading dependencies of the final pair.

## Accepted review corrections (CPU-validated, not real-video acceptance)

- Correction velocity is `Log(C_next @ C_current.T)` with `C = R @ R_initial.T`, preserving seconds/sqrt-dt weighting across the SO3 branch cut. The independently confirmed PnP world-motion convention is unchanged.
- Active SE3 reprojections carry finite weighted depth-restoration residuals and sparse bounded feasibility proposals. Initially negative depths can improve over multiple steps; feasible samples cannot regress. SO3 is not vetoed by inactive reprojections, zero-weight samples have no feasibility authority, and irreducible depth violations remain explicit per-frame uncertainty rather than freezing independent supported updates.
- A shared full-timeline visibility validator runs before standalone fitting and export. Display validity is separate from untouched source MANO validity/fitted poses. Explicit out-of-frame judgments clear geometry; uncertain supported reappearance logs full triangles again. Export no longer invents validity or visibility rows.
- P05/P09/appearance decision lineage binds the required exact current manifest/proposal and owned image identities, including selected frame/object. This is not pixel-inspection attestation. Final JSON preserves typed immutable raw/run identity and calibration null/hash; RRD also carries identity metadata.
- Linux owned-process supervision uses subreaping, process start identities and pidfds to reconcile detached descendants without signaling pre-existing jobs. Inner reconstruction shares 1000 seconds, outer producers have 1100 seconds, and the tool remains 1200 seconds. Exact inner phase/argv/timeout/returncode/elapsed/log/cleanup records propagate to the outer blocker; unresolved cleanup forbids automatic retry.

## Verified resume

Fresh runs are the default. Same-code/config successful prefixes can be explicitly resumed:

```bash
"$PREP_PYTHON" scripts/prepare_rgb_scene_runtime.py resume-contract \
  --bundle-root "$BUNDLE" --run-root "$RUN" --output "$NEW_RESUME_JSON"
```

Launch the same curated profile with `mode: verified_resume` and the exact resume contract path; every stage command includes `--resume-contract`. Resume checks raw/calibration/target contract, bundle/model code, successful producer DAG, decisions and visual evidence hashes. It skips only the identical successful command and leaves its hashes/logs unchanged. Changed assets/code, failed producers or partial unreceipted outputs are rejected; this first implementation does **not** support repair/retry migrations or copying predictions into a fresh run. Start a new run after a repaired failure rather than restamping old outputs.
