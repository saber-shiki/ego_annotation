# 基于可靠观测的下一阶段预处理方案

日期：2026-09-28。前置保存提交：`a42e974`。本文是设计方案，尚未实现或运行下一代算法；不修改当前冻结输出。

## 目标与非目标

目标是让单目 RGB 预处理输出的粗姿态/完整网格尽量由可解释的观测约束，且在观测不足时显式保留不确定性，使后续 RL 不必替预处理纠正大尺度错误。目标不是让每一帧都得到看似平滑的唯一姿态。

继续遵守：UniDepth/P09 原始数据固定；不改 MoGe、不造GT depth、不用CAD/GT/额外相机作预测；一个物体一个共享正尺度；完整三角网格和MANO保留；GT只在预测冻结后评价。

## 统一可靠性原则

可靠性不是每个视频一个标签，也不是单个 `eligible` 布尔值。它至少按以下维度逐帧记录：

- 观测族：RGB像素、appearance mask、可见表面候选、MANO深度顺序；
- 状态变量：旋转轴、平移轴、共享尺度、可见/隐藏表面；
- 时间区间：连续支持、短缺测、长缺测、重新出现；
- 证据是否独立：由相同mask/RGB派生的量不得被当成多票。

输出的置信度应该是优化权重和候选保留依据，不是阻止输出的硬门。

## 下一版管线结构

### A. 观测层：先保留真实观测，再生成模型绑定

1. **RGB correspondence layer**
   - LK/特征轨迹仅记录二维 `(frame, uv, forward/backward error, patch quality, mask membership, age)`。
   - 不立即把一个二维点永久变成某个SAM3D顶点/三角面材料点。
   - 轨迹短、遮挡后重现或重投影条件差时降低权重，保留历史状态但不伪造连续材料点。

2. **Mask boundary layer**
   - appearance mask作为二维可见投影证据；边界按局部是否被手遮挡、是否靠近图像边界、是否存在时间一致性分段赋权。
   - 不将被遮挡边界当作完整amodal轮廓；不以完整mesh包围盒拟合局部mask。

3. **Fixed visible-surface layer**
   - 继续使用原始UniDepth/P09候选，不回写 depth/cloud。
   - 把第一表面、深度置信、边界尾部和当前手深度顺序记录为不确定性，而非一个全帧5mm常数。
   - 由于五例 `object_surface_ownership_filter.state` 全为 `disabled`，下一版必须把表面候选称为 `candidate_visible_surface`；可以作为条件参考，但不能把其点全部视为独立无手污染观测。

4. **MANO ordering layer**
   - 只作为软遮挡/深度顺序先验，并携带原始confidence和visibility state。
   - 不把 `valid` 或低分辨率无冲突转成接触、非穿透或指尖准确约束。

### B. 姿态候选层：至少保留竞争解

当前 `solvePnPRansac -> solvePnPRefineLM` 只输出一个候选，且输入点已经绑定到当前网格。下一版应：

- 从二维轨迹和当前状态产生多个PnP/局部优化候选，而不是只有EPnP一个分支；
- 对每个候选重新执行**第一表面可见性、自遮挡、正深度、二维重投影、mask边界**检查；
- 若一个绑定点在候选下落在网格第一表面后方超过其深度不确定度，则降权或解除该绑定，而不是继续把它作为刚性事实；
- 记录候选代价差、旋转/平移分歧和局部可观测性。如果候选代价接近，保留top-K进入时序，而不是用平滑强行选第一名；
- 候选切换需要图像证据和时间代价共同决定，允许真实大角度运动；不设置绝对45°/60mm上限。

这里不是“只用2D即可直接得到6D”的假设：候选可由当前旧姿态、不同关键帧绑定的PnP、近共面配置适用的替代解及局部扰动优化产生；每个3D绑定必须携带其来源关键帧/三角面与不确定性。它们都只是提案，不是彼此独立观测。用跨帧未参与拟合的完整tracklet/图像区域留出集和后续帧预测误差评分，而不是在候选各自重新选出的内点上比较。近共面法只在数学条件成立时生成候选，不能为某个物体类别写分支。

已知此前RootSIFT重定位、几何多假设尝试没有带来显著物理精度改善，所以本方案不是简单重新启用旧geometry relocalization。区别必须落在实际机制：跨候选共享的留出tracklet、逐帧第一表面绑定生命周期、按方向的可观测性、有限时序分支联合选择。若只是更多候选却继续按各自内点/轮廓分数挑选，属于重演已知失败，不应启动实验。

候选数/关键帧数/窗口长度需有统一计算预算：例如初始工程上限K=4、局部窗口8–16帧，之后由运行时间与候选覆盖证据修订，不按案例调参。完整150帧必须报告耗时；稀疏点/边界用于优化，完整原网格用于最终评价与视频，不用低面数代理冒充最终几何。

候选层是针对共同问题的关键机制：milk的RGB支持足以选出稳定分支，BBQ/mug/spatula的低纹理、局部或近平面支持则不会伪装成唯一确定姿态。

### C. 时序状态层：联合但不互相伪造

状态暂定为每帧 `SE(3)` 物体姿态、一个共享物体尺度、候选分支标识及各观测族的隐变量/置信度。目标函数按观测族分开：

```text
E = E_rgb_2d
  + E_mask_visible_boundary
  + E_visible_surface_point_to_plane
  + E_visibility_and_cheirality
  + E_MANO_depth_order
  + E_temporal_motion
  + E_candidate_switch
```

- `E_rgb_2d` 使用二维轨迹；只有经过候选下的可见性重检后，才转成模型点重投影约束。
- `E_visible_surface` 只约束第一可见表面法向方向；平面表面不提供切向位移和完整旋转信息，Jacobian方向要显式反映出来。
- `E_temporal_motion` 使用时间戳的速度/加速度先验，作为弱先验；观测支持强时不能压过真实运动。
- `E_candidate_switch` 惩罚无证据的分支抖动，但在二维轨迹、mask和表面可见性共同支持时允许切换。
- 深度缺测只增加不确定性，不制造一个新的深度观测。现有 world-correction bridge 可保留为初始方案，但下一版应输出 gap covariance/支持方向，不能让插值结果看起来与真实深度同等可靠。
- 优化使用按族的异方差尺度与独立的鲁棒损失；运动先验不应被同一个鲁棒损失饱和成廉价离群点。

### D. 尺度/表面配准层：继续后置

只在候选姿态冻结或候选轨迹联合选择后，拟合一个共享统一尺度和独立平移。尺度配准不能承担纠正旋转分支、生成形状错误或隐藏深度缺测的职责。固定UniDepth结果仍以“与该参考一致”为指标，不称为GT精度。

## 判别实验顺序

每个实验都必须产生完整五例视频和可复核数值；不接受只改JSON/阈值而不看实际网格渲染。

### 实验1：二维 correspondence 与模型绑定解耦

**改动**：候选生成先用二维轨迹和mask；只有候选姿态下第一表面可见性通过，才启用对应三角面重投影。保留旧绑定作为对照，不覆盖。

**预测**：如果共性主因是错误3D绑定，BBQ/mug/spatula的自遮挡矛盾帧、旋转分支和GT-free mask/表面残差会改善；milk应不退化。如果没有变化，说明绑定不是主要瓶颈，转向候选生成/形状。

### 实验2：top-K姿态候选与可观测方向

**改动**：在固定观测上保留K个候选，计算姿态Jacobian奇异值/候选代价间隔，输出候选分歧视频；不使用GT选候选。

**预测**：若白杯和红铲是多解，失败帧应出现小代价间隔、大旋转分歧和低奇异值方向；milk/soup支持较强时分歧应小。若候选均同向但都错，说明生成网格/观测外观不匹配，而非优化局部极小。

### 实验3：固定候选下的观测族留一法

**改动**：在同一top-K框架内分别去掉RGB、mask、visible-surface、MANO ordering各一族；仅作诊断和完整视频，不让GT决定配置。

**预测**：若删掉surface后姿态明显自由漂移，surface是位置/法向约束而非完整姿态真值；若删掉RGB后milk/soup退化而BBQ/mug变化小，说明各例的RGB支持差异真实；若删MANO几乎不变，现有大姿态错误不是手深度顺序主因。

### 实验4：缺测区间分层状态

**改动**：短gap（1–2帧）、中gap、长gap分别传播状态和协方差；不把bridge结果标作实测。

**预测**：milk的单帧gap可被邻域约束；spatula长gap应保留较宽旋转/深度不确定性，而不是生成看似确定的轨迹。如果宽不确定性仍无法解释视频，问题主要在模型姿态/形状而非depth bridge。

### 实验5：后置统一尺度回归

**改动**：所有候选选择和姿态时序结束后才拟合共享尺度；现有fixed-UniDepth配准仅作为后端。

**预测**：共享尺度变化应小，且不会替换候选旋转。若尺度显著随候选分支改变，说明原流程在用尺度吸收姿态/形状错误，需要停在候选层处理。

## 五例验收标准

这些是判别实验的观察目标，不是任意拒绝输出的门：

1. 每例输出完整150帧网格/MANO视频；不只看代表帧。
2. 记录top-K候选、候选分歧、可观测方向和gap covariance；不把唯一JSON状态当成果。
3. milk的f143/f148/f149不重新出现r2已修掉的深度/轮廓跳变。
4. BBQ不复现jump-r1“保护错误跟踪后半段漂移”；soup不因新候选层退化。
5. mug/spatula须能显示“哪些帧是多解/不可观测”，而不是仅凭低像素误差宣称修复；若视觉仍错，保留具体机制失败。
6. 现有固定UniDepth和源hash不变；不使用GT/CAD选择候选；R/t、网格、MANO和视频证据都可追溯。
7. 除jump问题外，不能只用步长下降作为成功。必须同时查看原RGB对照、可见表面残差/coverage、候选分歧和实际完整网格渲染。

## 本方案当前优先级

**先做实验1+2的联合候选层，暂不调整UniDepth、MANO或相机。** 这是最直接针对五例共同失败且不会破坏当前固定参考合同的机制。若实验1改善矛盾帧、实验2显示明显多解，再实现时序候选选择；若两者均不改变输出，则下一因果分支是生成网格外观/形状与RGB之间的不匹配，而不是继续增加平滑或深度权重。
