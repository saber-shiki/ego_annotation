# 可见表面运动约束＋软包络：五例三臂结果（2026-10-07）

## 结论

**实现并完成五例完整对照，但没有解决整体粗位姿问题，不替换默认 R6/RL 输入。**

- B 的新运动/表面约束确实改变完整 mesh 的 SE(3)，不是画框或新增状态标签。
  红铲后段有明显位置/朝向修复；其余案例多为小幅变化，旋转并非全面改善。
- C 的框在 milk、汤罐、BBQ、白杯中几乎没有额外收益。红铲会改变求解分支，
  但配对 GT 表面误差的平均变化反而略差，不能据中位数宣布框有效。
- 新结果有运动退化，尤其红铲的相邻旋转步长 P95 从约21°增到79°。
  这不是可接受的默认升级。保留原 A，不用轮廓改善抵消退化，也不自动用于 RL。

63项专项/预处理/冻结回归通过；原分组CPU套件143项运行，139通过、4跳过。

## 6. 因果解释与下一实际干预

- B减少一些独立材料点/表面残差并产生真实网格修复，说明新观测不是完全无效；
  但它只修复了部分帧，不证明原错误绑定是唯一主因。
- 四例包络包含比例中位数约99–100%，大部分时候hinge不活跃且与表面同源。
  同一有偏深度的摘要不能解决绝对尺度/距离偏差，不能靠事后加权制造收益。
- 红铲框会改变非凸求解的路径，但并无稳定独特物理收益；中位数改善伴随
  配对均值/部分投影退化，须保留反例。
- 原始运动候选常被R6固定mask参考拒绝（milk136帧、汤罐143帧）。这既可能是
  RGBD/深度运动偏差，也可能是固定生成shape/anchor不相容，不可直接删除mask保护。
- 当前候选做逐帧A回退投影，而时序校正仅弱鲁棒正则。红铲改善集中在少数帧
  并引入大跳变，与这种非联合可行性处理相容，但尚未用消融证明全部跳变来源。

**下一步应对最差的连续窗口实现联合可行轨迹更新：将固定mask/首表面可行性与
材料观测共同留在时序优化里，检查并降低坏材料边的影响，而不是逐帧回退后直接
导出；保留真实快速转动和缺测不确定性。** 同时做长程一致材料身份/loop检验，
区分运动、anchor和共享shape误差。只有该机制减少真实新增跳变且改善未对齐表面，
才能考虑提供新的RL初始化。绝对metric偏差仍需要合法预测侧独立尺度依据或显式
有偏观测模型；不读取GT尺寸回填，也不扩大RL动作兜底。本轮没有实现或宣称这些
下一机制已经完成，没有继续用同一批GT调权。
