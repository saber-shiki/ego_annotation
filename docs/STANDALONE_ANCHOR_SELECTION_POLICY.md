# Anchor 选择标准：保留原评分，视觉复核只处理明确例外

制定日期：2026-09-11。范围：独立 RGB 场景管线的 P09 几何 anchor；同时明确后续 appearance anchor 的衔接。

**核心决策：以原有能把本次 frame0 排到第一的候选算法为基础，不重设计权重，不另起一套主观排序。默认选现有 `ranked_candidates[0]`，在真实图像复核后确认；只有明确、可定位的缺陷才能否决。**

本文件与同分支的 runtime 文字规范是后续执行标准，不是新的评分实现或生产验收。当前 run、anchor145、frame0 独立对照、已有模型产物和已部署 bundle 均未修改。自动 exception 检查/双候选调度尚未实现，不宣称已有这些能力。

## 1. 保留哪一套原标准

基线为 `build_v19_visible_geometry_from_sam2_depth.py` 现有候选生成逻辑。历史 corrected P09 源码与当前生产源码的评分权重、优先组和排序规则一致；本次修正后也把 frame0 排在第一。

### 1.1 候选来源

只从当前 run、当前对象、当前帧的有效可见深度观测中生成候选。RGB、mask、相机、深度必须能建立正确的同帧/图像平面对应。沿用已有生产者的 metric eligibility 和鲁棒深度规则，不另加一套“局部测量必须完美”的门槛。

- 文件缺失、对象/帧错配、空输入、坐标/单位无法解释：属于机械无效，不能强行当 anchor。
- 部分遮挡、局部 mask 缺口、噪声深度：通常是质量和不确定性问题，不是整条管线停机理由。
- 不能把保留了 appearance 的像素自动当作可信 metric；raw appearance、owned appearance 和 retained metric 的含义不变。

### 1.2 先保留原有 preferred 分组

现有 `conditioning_coherence_preferred` 同时考虑：

1. owned mask 为单连通分量；
2. mask 面积及可见深度采样支持足够；
3. 不贴近画面边缘。

原阈值保持不变：

- mask 面积至少 `max(1000, ceil(0.20 × 当前候选最大面积))`；
- 可见深度采样点至少 `max(100, ceil(0.20 × 当前候选最大点数))`；
- 边缘判定沿用生产者现有的源图像短边3%安全带。

这些是原有的**候选优先分组**，不是物理正确性或mask有效性的最终门槛。非preferred帧仍可作为观测；无preferred候选时沿用其余候选评分并记录局限，不人为制造必失败条件。

### 1.3 保留原有七项加权评分

所有分项为现有归一化项；分组内按分数降序，精确同分按原有 frame_idx 升序。

| 分项 | 原权重 | 原计算含义 |
|---|---:|---|
| 物体 mask 面积 A | **0.24** | 当前面积 / 候选最大面积 |
| 可见深度支持 P | **0.16** | 当前采样点数 / 候选最大采样点数 |
| 手部扣除比例 H | **0.18** | `1 − clip(removed_fraction, 0, 1)` |
| 不靠画面边缘 B | **0.16** | 非边缘为1，否则0 |
| 几何尺度一致性 E | **0.14** | `exp(-abs(log(当前extent对角线 / 候选中位extent对角线)))` |
| 连通性 C | **0.07** | `max(0, 1 − 0.25 × (分量数 − 1))` |
| 深度稳定性 D | **0.05** | 深度p95−p05跨度相对候选跨度p90的反向归一化，沿用原实现 |

```text
S = 0.24A + 0.16P + 0.18H + 0.16B + 0.14E + 0.07C + 0.05D
排序 = preferred组优先 → S降序 → frame_idx升序
```

不得因为此次案例而调权、硬编码对象类别、写死 frame0 或要求所有对象都必须露出两个平面。

**分项的限制也保留为限制：**

- 采样点数有上限，两帧都是2500点不意味着原始可见支持一样多。
- standalone 的 front-only 扣除在 P09 前完成，关闭 P09 内部二次盲扣后，其 `hand_owned_removed_fraction` 可能都为0。因此 H=1 不证明“完全无遮挡”，本轮不悄悄替换其定义或重算权重。
- 较小深度跨度可能来自正面视图；不能据此另行把“越平越好”提升为主观最高优先级。

## 2. 默认选择规则

1. 读取当前 `ranked_candidates`，将第1名作为**默认 anchor**。
2. 查看当前候选审阅图，并单独查看默认候选的原始 RGB、实际将送入 SAM3D 的 mask，以及对应 metric 支持摘要。
3. 没有第3节的明确缺陷：确认第1名，记录真实判断，不因为“更正、更居中、mask更平滑”另选低分帧。
4. 第1名确有明确缺陷：在同一原排序中依次检查下一候选，选择首个没有该缺陷的候选。不跳到拼图中“看着顺眼”的远后位候选。
5. 同分/近似难分且无明确缺陷：仍优先原排序，不建立新的主观评分。

这不是无条件机器接受：选中的 RGB/mask 仍必须实际查看，判断文件仍须绑定现有要求的证据。区别在于：**数值排序是主线，视觉复核是纠错，而不是不受约束地覆盖主线。**

## 3. 允许否决高分候选的明确情形

| 允许的例外 | 必须指出的实际证据 |
|---|---|
| 目标识别/归属错误 | mask主要覆盖了手、背景或另一个对象，而非选中的目标 |
| 严重模糊/曝光导致信息丢失 | 指出关键边界/部件在原图中不可辨，不能只写“看起来不够清楚” |
| 明显截断或关键结构被大面积遮挡 | 指出哪部分形状信息丢失、为何影响单视图重建；有可用替代时才降级该候选 |
| mask对关键结构存在明确严重错误 | 例如把重要外轮廓/部件切掉，或把大片非目标并进对象；不是普通手接触缺口 |
| 当前metric支持失配/退化 | 同帧深度/相机实际无法支持当前所需的metric定位/尺度，依据生产者证据而非主观想象 |

下面**不能单独作为否决理由**：

- 有手接触或局部不规则边缘；
- 另一帧更正面、更居中、mask更“漂亮”；
- 单帧深度跨度稍小；
- 对象变小之后视觉上显得更干净；
- 数值排名不符合主观预期；
- 将未知背面想象为某种类别标准形状。

对于不存在明显更好观测的片段，选择有用的近似候选并保留不确定性，不陷入不断寻找“完美anchor”的循环。

## 4. 覆盖默认结果时必须如何复核

- **默认第1名与拟选替代者都要单独读原图和实际mask。** 不能一方只看小拼图、另一方看放大原图。
- 全帧用相同显示尺寸；若比较细节，使用相同缩放因子，注明原始mask像素面积。禁止把较小对象放大后误当成同等真实分辨率。
- 查看同尺度结构细节，判断所谓“手形凸起”究竟是目标轮廓、遮挡边界，还是已证实的mask污染。
- 必须记录默认候选的具体缺陷、影响的结构、替代候选是否解决，以及其分辨率/可见面/遮挡方面的代价。
- 必须分开记录 `global_rank`、`review_panel_rank` 和 `proposal_score`。候选拼图的时间多样性抽样只改变审阅集合，不改全局优先级。

现有判断schema不需要为本标准增加一整套新门禁；上述内容可写入现有 `visual_rationale`、`rejected_candidate_observations`、`uncertainties`。当前 `selected_candidate_rank` 含义易混，正文必须明确其对应哪种排名；后续代码接线再添加无歧义字段，不能追改旧判断。

## 5. 什么时候才做双候选重建

默认只重建一个候选，不对所有帧跑SAM3D。

只有以下情况才考虑对照：

- 对默认候选存在具体但不能仅靠图像确认的严重mask/结构疑点；
- 对一个低分替代者的偏好与默认排序冲突，但证据不足以直接否决默认候选；
- 已生成mesh出现输入/其他当前观测不支持的明显部件或结构。

默认预算：**最多两个候选、每个一次、相同模型/seed/配置**。若默认候选已经执行，只补一次替代，不重复默认、不换seed挑好看的结果。额外预算需要明确授权；runtime没有已授权的对照入口时向父级提出两候选与理由，不自行绕开执行规范。

比较依据是**当前视频证据的解释能力**：完整mesh是否引入无支持结构、是否保留可见特征、是否合理解释当前其他视角。不能仅用mask IoU、watertight、面数或主观审美评判。

检查若需视角/尺度绑定，使用同一已验证的几何流程；不得对某候选进行额外手工拟合后再宣称公平胜出。单视图隐藏面仍为假设。对照不等于自动修改生产anchor，结果采用必须走显式新绑定。

## 6. P09几何anchor与后续appearance anchor

- **本标准首先约束 P09几何anchor**：保留上述原七项评分，选定后同时用于当前metric/gauge和第一轮单视图几何。
- 后续appearance重建已有独立选择器，仍保留其原公式：`0.45×面积 + 0.35×清晰度 + 0.20×边缘安全距离`；边距达到5%短边后饱和，不额外奖励远离边缘或居中。
- 不把两个评分混成新的未经验证的总分。appearance阶段同样采取“原排序优先，视觉只处理明确例外”，并保留同帧metric支持/已实现尺度绑定要求。
- 两类anchor可以不同，但必须通过已实现的原生相机到当前canonical gauge转换；不能把新的原生PLY直接套在旧anchor姿态上。
- 某帧适合外观但无可靠metric观测时，不把它晋升为metric authority。若当前绑定不支持该组合，另用可绑定候选，或将其保留为独立诊断，而非伪造尺度。

## 8. 落地范围与验证要求

本次变更：

- 文档明确定义原评分、默认选择、有限否决与复核规则；
- 在隔离源码分支的runtime规范中写入同样的“原排序优先”约束；
- 不修改候选算法、权重、模型代码、现有判断或runtime bundle，不执行模型；
- 不宣称自动否决检测、自动双候选调度或新评分器已经实现。

后续真正接线需要覆盖的最小回归：

1. 原数值评分/排序不变，当前候选仍为frame0第一；
2. 无明确缺陷时不能仅凭“更干净”覆盖第一名；
3. 存在明确目标/严重输入错误时，允许沿原顺序选下一有效候选；
4. 覆盖候选的两边都有同尺度原图/mask检查证据，global/review排名不混；
5. 局部遮挡/噪声不被误升级成整条管线失败；
6. 有界对照只用当前输入，保存各自完整网格，不改旧产物和来源。
