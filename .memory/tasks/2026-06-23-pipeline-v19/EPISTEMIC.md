## Current causal model

The object-registration failure chain was systematic: wrong segmentation support produced wrong visible surfels, which produced wrong completion/pose, which then rendered wrong object geometry. OWLv2 text-grounded detection changes the first cause by giving SAM2 boxes tied to the keyboard footprint rather than agent/VLM pixel guesses; direct visible pose residuals and final render consumption support that this repaired the dominant object-registration mechanism for the bounded clip.

The MANO interval failure is a different systematic error. The interval solver appears to preserve hand shape/articulation relative to the wrist but changes the global wrist/root placement, especially for the right hand. That pattern is predicted by an optimizer that treats object/contact/visible-surface constraints as stronger than noisy hand observation evidence in ambiguous contact intervals: it can move a plausible hand skeleton toward the keyboard/contact hypothesis without improving camera-coordinate MANO agreement. Normal measurement noise would perturb both sides or wrist-relative shape more symmetrically; the observed right-dominated translation degradation is more consistent with systematic constraint weighting, contact ownership, or source-frame/root-prior coupling error.
